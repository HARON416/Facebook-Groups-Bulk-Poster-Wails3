# Website design

- Use Impeccable for design changes and preserve the established Postika identity.
- Do not add decorative status dots, dotted backgrounds, faux browser-window
  dots, or middle-dot separators. Use spacing, alignment, and typography to
  organize content. This is an explicit preference from the project owner.
- Preserve the owner-supplied Windows, macOS, and Linux SVG icons.
- Use plain, useful copy. Keep release notices consistent with actual signing,
  update delivery, and queue persistence behavior; never invent availability.
- Check changed pages in the browser at desktop and phone widths, including
  wrapping, overflow, keyboard focus, and readable contrast.
